# CCProxy 项目模型行内状态布局设计

日期：2026-10-26
状态：已与用户确认采用方案 A

## 目标

降低项目管理表格中下拉框的视觉重量，并把 Claude/Codex 的同步状态从下拉框下方的文字徽章
改为紧跟在对应模型选择框后的状态圆标。

## 布局

- 保持三列表格：项目、Claude 默认模型、Codex 默认模型。
- 模型选择框不再铺满整列，最大宽度约 250px；状态圆标紧随其后。
- 未绑定的选择框显示为轻量的“未设置”，使用透明背景和虚线描边；打开菜单后仍保留
  “不设置（停止托管）”的完整语义。
- 项目路径继续使用等宽字体并在空间不足时省略；来源仍显示为 Codex/Claude 小徽标。
- 状态圆标不增加独立状态列，也不参与点击操作。

## 状态表达

| 状态 | 图标 | 颜色 |
|---|---|---|
| `ok` | 勾 | 成功绿 |
| `binding_invalid` | 感叹号 | 警告橙 |
| `project_missing` | 感叹号 | 警告橙 |
| `restart_required` | 感叹号 | 警告橙 |
| `requires_project_trust` | 感叹号 | 警告橙 |
| `config_unreadable` | 感叹号 | 错误红 |
| `write_failed` | 感叹号 | 错误红 |

- 圆标带有可访问标签和原生提示文本，内容为状态中文名；存在后端消息时一并展示。
- 没有绑定或没有同步状态时不显示圆标。
- 状态不再以下方文字 Badge 的形式重复出现。

## 交互与错误处理

- 保存、清除、离线绑定和忙碌状态逻辑不变。
- 窄窗口下模型选择框可收缩，状态圆标保持固定尺寸；路径列优先截断。
- 状态仅用于展示，点击选择框的行为不变。

## 非目标

- 不改变后端接口、候选模型、绑定结构或同步规则。
- 不增加第四列，不增加编辑/删除按钮。
- 不改变目录按完整路径升序的排序规则。

## 验收

- 每个 Claude/Codex 模型控件在同一行显示选择框和状态圆标。
- 未设置样式明显弱于已设置样式，但菜单语义不变。
- 成功使用绿色勾，警告使用橙色感叹号，错误使用红色感叹号。
- 圆标的 `title`/ARIA 文案能区分状态和具体消息。
- 页面在现有最小窗口宽度下无横向溢出，状态圆标不被截断。
- `npm run build` 通过，并通过本地浏览器截图检查布局。
