# CCProxy 项目模型行内状态布局设计

日期：2026-10-26
状态：已与用户确认采用方案 A

## 目标

降低项目管理表格中下拉框的视觉重量，并把 Claude/Codex 的同步状态从下拉框下方的文字徽章
改为紧跟在对应模型选择框后的状态圆标。

## 布局

- 顶部导航顺序调整为：模型映射、项目管理、请求日志、用量统计、设置。
- 保持三列表格：项目、Claude 默认模型、Codex 默认模型。
- 模型选择框不再铺满整列，最大宽度约 250px；状态圆标紧随其后。
- 下拉选项使用 `{ value: '', label: '未设置', menuLabel: '不设置（停止托管）' }`：收起时
  显示轻量的“未设置”，打开菜单后仍保留完整语义。
- 未绑定状态根据 `mappingId` 为空决定，使用透明背景和虚线描边，不复用现有 placeholder 类。
- 项目路径继续使用等宽字体并在空间不足时省略；来源仍显示为 Codex/Claude 小徽标。
- 状态圆标不增加独立状态列，也不参与点击操作。

## 状态表达

| 状态 | 图标 | 颜色 |
|---|---|---|
| `ok` | 勾 | 成功绿 |
| `binding_invalid` | 感叹号 | 警告橙 |
| `project_missing` | 感叹号 | 警告橙 |
| `restart_required` | 感叹号 | 警告橙 |
| `requires_project_trust` | 感叹号 | 警告橙 |
| `config_unreadable` | 叉号 | 错误红 |
| `write_failed` | 叉号 | 错误红 |
| `sync_disabled` / 未知状态 | 问号 | 中性灰 |

- 警告使用感叹号，错误使用叉号，避免只靠颜色区分严重程度。
- 圆标可通过鼠标悬停或键盘聚焦显示自绘提示文本；同时提供包含客户端、状态中文名和后端
  消息的 ARIA 标签。例如：“Claude 同步状态：写入失败，配置不可读”。
- 没有绑定或没有同步状态时不显示圆标。
- 状态不再以下方文字 Badge 的形式重复出现。

## 交互与错误处理

- 保存、清除、离线绑定和忙碌状态逻辑不变。
- 窄窗口下模型选择框可收缩，状态圆标保持固定尺寸；路径列优先截断。
- 状态仅用于展示，点击选择框的行为不变。
- 状态圆标带 `tabindex="0"`，悬停或聚焦时用 `data-tooltip` 风格的 CSS 提示显示完整状态；
  状态圆标没有点击动作。

## 非目标

- 不改变后端接口、候选模型、绑定结构或同步规则。
- 不增加第四列，不增加编辑/删除按钮。
- 不改变目录按完整路径升序的排序规则。
- 不增加新的顶部导航项。

## 验收

- 每个 Claude/Codex 模型控件在同一行显示选择框和状态圆标。
- 未设置样式明显弱于已设置样式，但菜单语义不变。
- 成功使用绿色勾，警告使用橙色感叹号，错误使用红色叉号。
- 圆标的可聚焦提示和 ARIA 文案都能区分客户端、状态和具体消息。
- 页面在现有最小窗口宽度下无横向溢出，状态圆标不被截断。
- “项目管理”紧跟在“模型映射”后面，其余入口相对顺序不变。
- `npm run build` 通过，并通过本地浏览器截图检查布局。
